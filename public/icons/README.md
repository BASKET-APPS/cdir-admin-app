# Iconos de marca

`google.svg` es el icono de acceso de Google distribuido por Firebase UI, alojado localmente para no realizar una petición de imagen externa al cargar el acceso.

Origen: https://www.gstatic.com/firebasejs/ui/2.0.0/images/auth/google.svg

Referencia de uso de marca: https://developers.google.com/identity/branding-guidelines

El resto de iconos de la interfaz utiliza Lucide React.
